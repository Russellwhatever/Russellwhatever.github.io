RSSAbout

2026-04-01

一个将 RSS 订阅自动整理为每日新闻简报的工具。读取 OPML 订阅文件，抓取当日文章，通过 LLM 提取事件、去重归类，最终输出 Markdown 日报，可选转换为 HTML 或 PDF。

支持两阶段 LLM 流水线（先逐篇提取事件，再跨来源去重合并），也提供关键词分类作为无 LLM 时的备选方案。兼容 OpenAI 系 API 和 Claude，API Key 通过环境变量注入，不写入配置文件。支持 macOS launchd 和 Linux crontab 定时自动运行。MIT 协议开源。
